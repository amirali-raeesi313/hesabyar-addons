# هوش پیش‌بین حساب‌یار (erp_auto_ai)

پیش‌بینی فروش/تقاضا و تشخیص ریزش مشتری. هسته کاملاً **آماری و قابل‌توضیح** است
(بدون وابستگی به اینترنت)؛ اگر کلید DeepSeek تنظیم باشد، فقط «توضیح انسانی» را
غنی می‌کند و هرگز عددی نمی‌سازد. بخش‌های ۸ و ۱۵ پرامپت و ردیف‌های پیش‌بینی اکسل.

## مدل‌ها
| مدل | نقش |
|---|---|
| `erp.auto.forecast` | پیش‌بینی هر کالا: افق ۷/۳۰/۹۰ روز، میانگین متحرک + روند خطی، سطح اطمینان (تعداد داده + پراکندگی)، پیشنهاد تأمین، ریسک کمبود |
| `erp.auto.churn` | ریسک ریزش هر مشتری: میانگین فاصله‌ی خرید در برابر روزِ گذشته از آخرین خرید؛ نسبت >۱.۵ متوسط، >۲.۵ شدید |

## روش (قابل حسابرسی)
- منبع داده: فاکتورهای فروش نهایی‌شده (`account.move`).
- پیش‌بینی = (میانگین ماهانه + روند) مقیاس‌شده به افق؛ اطمینان از تعداد دوره و ضریب تغییرات.
- ریزش = روزِ گذشته ÷ میانگین فاصله‌ی خرید.
- هر اجرا Idempotent است (upsert per کالا/مشتری) و در لاگ حسابرسی ثبت می‌شود.

## اجرا
- دستی: منوی «هسته اتوماسیون ← پیش‌بینی هوشمند ← تولید پیش‌بینی / محاسبه ریزش».
- خودکار: دو کرون هفتگی (پیش‌فرض خاموش).

## تست
```
odoo-bin -d <db> -i erp_auto_ai --test-enable --test-tags /erp_auto_ai --stop-after-init
```
۷ تست: ریاضی آماری، تولید پیش‌بینی + Idempotency، روند صعودی، ریزش شدید/کم، حداقل ۲ خرید.

## گام بعد
افزودن فصلی‌بودن (مناسبت‌های شمسی/قمری: محرم، اربعین، رمضان، نوروز) و تغذیه‌ی
پیشنهاد تأمین به عامل خرید (`erp_auto_agent`).
