# مدیریت کیفیت حساب‌یار (erp_auto_quality)

جایگزین Community برای ماژول کیفیت Odoo (که فقط Enterprise است). حوزه‌ی «مدیریت
کیفیت» اکسل SAP را پوشش می‌دهد: بازرسی ورودی/تولید/نهایی، نمونه‌برداری، معیار
پذیرش، ثبت عیب، قرنطینه، عدم انطباق و اقدام اصلاحی/پیشگیرانه (CAPA)، کیفیت
تأمین‌کننده و شکایت مشتری.

## مدل‌ها
| مدل | نقش |
|---|---|
| `erp.auto.quality.point` | قاعده‌ی بازرسی: محرک (ورودی/تحویل/تولید/دستی)، دامنه‌ی کالا، معیار (قبول-رد یا کمی با بازه مجاز)، قرنطینه در صورت رد |
| `erp.auto.quality.check` | نمونه‌ی بازرسی روی یک کالا/محموله؛ قبول/رد/قرنطینه؛ ارزیابی خودکار کمی |
| `erp.auto.quality.alert` | عدم انطباق + CAPA: علت ریشه‌ای، اقدام اصلاحی/پیشگیرانه، اثربخشی، چرخه‌ی حالت |

## اتوماسیون
- **بازرسی خودکار روی رسید:** پس از تأیید حواله‌ی ورودی، برای کالاهای مشمولِ نقاطِ نوع «دریافت»، بازرسی خودکار ساخته می‌شود (override ایمن روی `stock.picking.button_validate`؛ خطا جریان انبار را مسدود نمی‌کند؛ Idempotent).
- **رد بازرسی → CAPA خودکار + قرنطینه** و ثبت در لاگ حسابرسی (`erp_auto_core`).
- **ارزیابی خودکار کمی:** مقدار خارج از بازه‌ی مجاز → رد.
- کالای دارای تأمین‌کننده که رد شود ⇒ عدم انطباق از نوع «کیفیت تأمین‌کننده».

## تست
```
odoo-bin -d <db> -i erp_auto_quality --test-enable --test-tags /erp_auto_quality --stop-after-init
```
۱۰ تست: تطبیق دامنه، رد→CAPA+قرنطینه، Idempotency، کیفیت تأمین‌کننده، ارزیابی کمی
قبول/رد، چرخه‌ی CAPA، گارد اتصال انبار.

## گام بعد
اتصال بازرسی به دستور تولید (mrp) و تحویل؛ داشبورد نرخ عدم انطباق per تأمین‌کننده
(تغذیه‌ی امتیاز تأمین‌کننده در عامل خرید).
